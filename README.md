# Lógica e C — Do Zero ao Primeiro Projeto

Portal educacional para iniciantes, com 11 trilhas que conduzem o aluno desde a preparação do Dev-C++ até a construção e evolução de um CRUD persistente em linguagem C.

## Conteúdo

- Trilha 00 — Preparando o ambiente
- Trilha 01 — Algoritmos e pensamento lógico
- Trilha 02 — Variáveis, tipos e entrada
- Trilha 03 — Estruturas de decisão
- Trilha 04 — Estruturas de repetição
- Trilha 05 — Funções e organização
- Trilha 06 — Vetores, matrizes e textos
- Trilha 07 — Estruturas e registros
- Trilha 08 — Arquivos de texto
- Trilha 09 — Primeiro projeto: CRUD
- Trilha 10 — Evoluindo o CRUD

O curso utiliza exclusivamente linguagem C, arquivos `.c` e o compilador GCC/MinGW no Dev-C++.

## Tecnologias do portal

- Next.js 16.2.6
- React 19
- TypeScript
- App Router
- CSS responsivo
- Tema claro e escuro

## Execução local

Requisito: Node.js 22.13 ou superior.

```bash
npm install
npm run dev
```

Para conferir a compilação destinada à Vercel:

```bash
npm run build:vercel
```
